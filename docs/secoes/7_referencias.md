# Referências

As referências utilizadas no trabalho foram:

- ABRELPE – ASSOCIAÇÃO BRASILEIRA DE EMPRESAS DE LIMPEZA PÚBLICA E RESÍDUOS ESPECIAIS. **Panorama dos Resíduos Sólidos no Brasil 2022**. São Paulo: ABRELPE, 2022.
- BRASIL. **Lei nº 12.305, de 2 de agosto de 2010**. Institui a Política Nacional de Resíduos Sólidos. Diário Oficial da União, Brasília, DF, 3 ago. 2010. Disponível em: https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2010/lei/l12305.htm.
- BRASIL. **Lei nº 13.709, de 14 de agosto de 2018**. Lei Geral de Proteção de Dados Pessoais (LGPD). Diário Oficial da União, Brasília, DF, 15 ago. 2018.
- CONSELHO NACIONAL DO MEIO AMBIENTE (CONAMA). **Resolução nº 275, de 25 de abril de 2001**. Estabelece o código de cores para os diferentes tipos de resíduos. Brasília, DF, 2001.
- BROWN, Tim. **Design Thinking**: uma metodologia poderosa para decretar o fim das velhas ideias. Rio de Janeiro: Alta Books, 2020.
- HEUSER, Carlos Alberto. **Projeto de banco de dados**. 6. ed. Porto Alegre: Bookman, 2009.
- NIELSEN, Jakob. **10 Usability Heuristics for User Interface Design**. Nielsen Norman Group, 1994. Disponível em: https://www.nngroup.com/articles/ten-usability-heuristics/.
- OSTERWALDER, Alexander et al. **Value Proposition Design**: como construir propostas de valor inovadoras. São Paulo: HSM, 2014.
- SCHWABER, Ken; SUTHERLAND, Jeff. **O Guia do Scrum**. 2020. Disponível em: https://scrumguides.org/.
- VALENTE, Marco Tulio. **Engenharia de Software Moderna**: princípios e práticas para desenvolvimento de software com produtividade. Belo Horizonte: Independente, 2020. Disponível em: https://engsoftmoderna.info/.
- W3C. **Web Content Accessibility Guidelines (WCAG) 2.1**. 2018. Disponível em: https://www.w3.org/TR/WCAG21/.
